方言差异说明（必读）：网页端引擎 = SQLite；权威源 = SQL Server
  • 取前 N 行：SQL Server 用 TOP n（SELECT TOP 10 ...）；SQLite 用 LIMIT n（写在 ORDER BY 之后）。
  • 当前时间：SQL Server 用 GETDATE()；本题库全库禁用动态时间，基准日写死为 2026-06-30，请直接用日期字面量。
  • 自增主键：SQL Server 用 IDENTITY(1,1)；SQLite 用 INTEGER PRIMARY KEY AUTOINCREMENT。
  • 字符串类型：SQL Server 用 NVARCHAR(n) / VARCHAR(n)；SQLite 统一 TEXT（无长度限制）。
  • 字符串拼接：SQL Server 用 +；SQLite 的 + 是数值加法，拼串必须用 ||。
  • 对象前缀：SQL Server 写法带 dbo. 前缀；SQLite 去掉前缀，直接写表名。
  • 空值替换：SQL Server 用 ISNULL(a, b)；SQLite 用 IFNULL(a, b)（通用写法 COALESCE(a, b) 两边都能跑）。
  • 字符串比较语义：SQL Server 裸 = 默认忽略大小写与尾空格；SQLite 逐字精确。题干涉及字符串匹配时会要求 UPPER() / TRIM() 或 LIKE。
  • 日期：库里日期以 ISO 文本 YYYY-MM-DD 存储，字典序即时间序，可直接用字符串比较。

另有差异：SQL Server 字符串相加 'a' + 'b' 得 'ab'，SQLite 里 'a' + 'b' 得 0（静默错误，务必用 ||）；SQL Server 有 CONVERT，SQLite 用 CAST 或 strftime。

权威源 = SQL Server（reference_sql）；网页端可执行引擎 = SQLite（reference_sql_sqlite，判题预期结果由它在同一个库上现场跑出）。两者不一致时以 SQL Server 为准。
